# Complete Tools Reference

## Overview

This reference provides a consolidated overview of all tools covered throughout the **13-module DevOps learning path**.

Each module includes:

* 🛠️ Primary DevOps tool.
* ☁️ AWS alternative or equivalent service.

# DevOps Tools Reference Table

| Module                      | Primary Tool            | AWS Alternative           | Key Commands / Operations           |
| --------------------------- | ----------------------- | ------------------------- | ----------------------------------- |
| 1. Linux                    | Ubuntu / Bash           | AWS CloudShell            | `ssh`, `chmod`, `grep`, `ps`        |
| 2. Python Automation        | Python 3 + Boto3        | AWS Lambda                | `python3`, `pip`, `pytest`          |
| 3. Infrastructure Setup     | AWS CLI                 | AWS CloudShell            | `aws configure`, `aws ec2`          |
| 4. DevOps Concepts          | DevOps Toolchain        | AWS Services              | SDLC lifecycle awareness            |
| 5. Version Control          | Git + GitHub            | AWS CodeCommit            | `add`, `commit`, `push`, `merge`    |
| 6. Containerization         | Docker + Docker Compose | Amazon ECS / Amazon ECR   | `build`, `run`, `push`, `compose`   |
| 7. Configuration Management | Puppet OSS              | AWS OpsWorks              | `puppet apply`, `puppet agent`      |
| 8. Configuration Management | Ansible                 | AWS Systems Manager (SSM) | `ansible`, `playbook`, `galaxy`     |
| 9. Continuous Testing       | Selenium + Maven        | AWS Device Farm           | `mvn test`, `chromedriver`          |
| 10. CI/CD                   | Jenkins                 | AWS CodePipeline          | Pipeline, `Jenkinsfile`             |
| 11. Container Orchestration | Kubernetes / EKS        | Amazon EKS                | `kubectl`, `eksctl`, `helm`         |
| 12. Monitoring              | ELK Stack               | CloudWatch + OpenSearch   | Elasticsearch API, Kibana, Filebeat |
| 13. Infrastructure as Code  | Terraform               | AWS CloudFormation        | `init`, `plan`, `apply`, `destroy`  |
